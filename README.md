# Digi World Universe

GitHub Pages-ready static website for **digiuniverse.world**.

## Included
- `index.html` — latest website source
- `CNAME` — custom domain configuration for `digiuniverse.world`

## Required media assets
The latest HTML references these local files. Add the original files to the repository root to preserve the current visual design exactly:

- `DiGi Logo (1).jpg`
- `digi-world-promo.mp4.mp4`
- `Boss IO.mp4`
- `Boss.mp4`
- `Package 1.png`
- `Package 2.png`
- `package 3.png`
- `package 4.png`

The source HTML was preserved without redesigning the site.

## GitHub Pages
Repository: https://github.com/digiworlduniverse-creator/Digi-world-universe

Enable **Settings → Pages → Deploy from branch → main → / (root)**.
